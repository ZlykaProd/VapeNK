VapeNK #1 — версия для BotHost.ru

В корне архива находятся main.py и requirements.txt — это важно для автоопределения запуска BotHost.

Как установить:
1. Загрузите этот ZIP через функцию деплоя из архива на BotHost либо положите эти файлы в корень Git-репозитория.
2. В настройках BotHost укажите главный файл (точку входа): main.py (если поле доступно).
3. В переменных окружения BotHost задайте:
   BOT_TOKEN = НОВЫЙ токен Telegram-бота
   DEEPSEEK_API_KEY = НОВЫЙ ключ DeepSeek
   DEEPSEEK_MODEL = модель, доступная вашему API и поддерживающая входные изображения
   DB_PATH = /app/data/inventory.db
4. Выполните новый деплой, а не только рестарт. Проверьте логи сборки и запуска.
5. Каждый администратор должен открыть бота и отправить /start, чтобы получать уведомления.

Администраторы: @P0huy02, @YaZlyka, @miii69_54.
При создании заявки остаток товара не уменьшается.

Важно: распознавание фото работает только если выбранная модель/API реально поддерживает изображения. Если DeepSeek отвечает ошибкой о неподдерживаемом image input, задайте поддерживаемую vision-модель из доступных в вашем аккаунте.

Безопасность: токены и API-ключи не встроены в архив. Не отправляйте их в чат и не коммитьте в Git. Ранее раскрытые ключи необходимо отозвать и выпустить заново.
