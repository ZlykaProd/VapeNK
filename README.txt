VapeNK #1 — TELEGRAM BOT

1. Установи Python 3.12.
2. Распакуй архив.
3. Открой терминал в папке проекта.
4. Установи зависимости:
   pip install -r requirements.txt
5. Скопируй .env.example в .env и заполни BOT_TOKEN и DEEPSEEK_API_KEY.
6. Запусти:
   python bot.py

ВАЖНО:
- Не публикуй .env и API-ключи. Токен Telegram встроен в bot.py по твоей просьбе. После теста обязательно отзови его через @BotFather командой /revoke и замени новым.
